\# 🏏 Virat Kohli vs MS Dhoni — Cricket Performance Dashboard



An interactive \*\*Microsoft Power BI dashboard\*\* comparing the career performance and key statistics of \*\*Virat Kohli\*\* and \*\*MS Dhoni\*\* through data visualization and interactive analysis.



\---



\## 📌 Project Overview



This project presents an interactive comparison of two of India's most prominent cricketers — \*\*Virat Kohli\*\* and \*\*MS Dhoni\*\*.



The dashboard transforms cricket statistics into an easy-to-understand visual analytics experience, allowing users to explore player performance and compare key career metrics.



The dashboard focuses on:



\* Batting performance

\* Runs and matches

\* Average and strike rate

\* Career performance trends

\* Player-wise statistical comparison

\* Interactive player selection



\---



\## 🎯 Objective



The primary objective of this project is to use \*\*data analytics and visualization\*\* to answer questions such as:



\* How do Virat Kohli and MS Dhoni compare statistically?

\* Who has scored more runs?

\* How do their batting averages compare?

\* How does their strike rate differ?

\* How do their career performances compare across key metrics?

\* What insights can be derived from their career statistics?

\## 📊 Dashboard Features



\### 👑 Virat Kohli Analysis



The dashboard provides a detailed view of Virat Kohli's performance through key statistical indicators and visualizations.



Analysis includes:



\* Total runs

\* Matches played

\* Batting average

\* Strike rate

\* Career performance

\* Statistical trends



\### 🧢 MS Dhoni Analysis



The dashboard provides a similar analytical view of MS Dhoni's career statistics.



Analysis includes:



\* Total runs

\* Matches played

\* Batting average

\* Strike rate

\* Career performance

\* Statistical trends



\### ⚔️ Player Comparison



The dashboard allows users to compare both players using interactive visualizations.



Key comparison areas include:



\* Total Runs

\* Matches

\* Batting Average

\* Strike Rate

\* Overall career performance



An interactive \*\*Player Slicer\*\* can be used to switch between the two players and explore their statistics.
